## Project Overview

This platform was developed as a technological solution within the university environment to optimize the recruitment, guidance, and academic counseling processes for prospective and current students. Utilizing a dynamic questionnaire centered on interest areas, cognitive skills, and personality traits, the system processes user responses in real time to generate a detailed professional affinity profile.

> **Scope Note:** This software serves as an auxiliary tool for initial exploration and rapid diagnosis; it does not replace the qualitative evaluation of a professional academic counselor or psychopedagogist.

## Key Features

* **User Registration Module:** Prior data collection to contextualize metrics and student background.
* **Dynamic Evaluation:** A sequential questionnaire structured by specific competence and aptitude blocks.
* **Client-Side Processing:** Career matching algorithms run entirely on the client side, ensuring instantaneous result generation.
* **Responsive Architecture:** A fluid, adaptive design optimized for both desktop workstations and mobile devices.
* **Serverless Approach:** Fully decoupled structure with no critical backend dependencies, facilitating high availability and zero infrastructure maintenance costs.

## Technical Stack

The development relies on standard web technologies focused on performance optimization and accessibility:

* **Structure & Semantics:** Advanced HTML5.
* **Design & Layout:** Native CSS3 utilizing a modular architecture.
* **Business Logic & Algorithms:** JavaScript (ES6+) for DOM manipulation, state management, and score calculation.
* **Deployment & CI/CD:** Netlify (automated hosting platform for static web environments).
